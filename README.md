# CreditWise Loan System

## 📌 Overview

CreditWise is a Machine Learning based loan approval prediction
system that predicts whether a loan is likely to be approved
based on applicant and loan-related information.

## 🔄 Machine Learning Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Missing Value Handling using SimpleImputer
5. Exploratory Data Analysis
6. Feature Engineering
7. Encoding
8. Feature Scaling using StandardScaler
9. Train-Test Split
10. Model Training
11. Model Comparison
12. Model Selection
13. Model Evaluation
14. Streamlit Deployment

## 🤖 Models

- Logistic Regression
- KNN
- Gaussian Naive Bayes

## 📊 Final Model

Gaussian Naive Bayes

Accuracy: 86%
Precision: 81.13%
Recall: 70.49%
F1 Score: 75.44%
